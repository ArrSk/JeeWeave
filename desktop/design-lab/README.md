## 画廊里可见的

### 四个方向（四种界面语言，各铺一部分）

| | 名字 | 视觉世界 | 一句话 |
| --- | --- | --- | --- |
| 一 | **涟漪** | 冷青水面、白卡、极淡波纹 | 一天是水面，安排是石子；近处有形，远处只是水光 |
| 二 | **舆图** | 土绿赭石、细经纬格、菱形界标 | 时间是疆域：对象是地块、事情是界标、今天是路线 |
| 三 | **夜场** | 深紫近黑、铜金、顶光 | 台上只站一件事，其余在两侧候场 |
| 四 | **经纬** | 暖纸 / 墨夜、一条经线、毛线八色 | 没有侧栏也没有工具栏，整窗一条经线 |

### 织机（`loom.html`）—— 收成一副骨架

把四个方向的经验合成一个能装下**全部 13 个页面**的壳，并且导航由**插件清单**渲染：

```
插件清单 ──┬─ 梭上的位置（导航）
          ├─ 页面注册（路由）
          ├─ 命令（面板里带 owner 前缀）
          └─ 开关（关掉即不可达，可声明依赖）
```

- 关掉笔记 → 梭上少一枚 → 直接开 `#notes` 说「笔记 · 已关闭」→ 再打开就回来
- 关掉课程表 → 教务导入标成**阻塞**，导入页给出「它依赖课程表」
- **挂起**（群消息）：界面在，开关禁用
- **未实装**（记账）：位置在，功能没有，如实标注
- 四种材质（纸 / 水 / 图 / 场）随换随生效，骨架不动
