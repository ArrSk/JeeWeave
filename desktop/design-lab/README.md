## 画廊里可见的

### 四个方向（四种界面语言，各铺一部分）

| | 名字 | 视觉世界 | 一句话 |
| --- | --- | --- | --- |
| 一 | **涟漪** | 冷青水面、白卡、极淡波纹 | 一天是水面，安排是石子；近处有形，远处只是水光 |
| 二 | **舆图** | 土绿赭石、细经纬格、菱形界标 | 时间是疆域：对象是地块、事情是界标、今天是路线 |
| 三 | **夜场** | 深紫近黑、铜金、顶光 | 台上只站一件事，其余在两侧候场 |
| 四 | **经纬** | 暖纸 / 墨夜、一条经线、毛线八色 | 没有侧栏也没有工具栏，整窗一条经线 |

### 织机（`loom.html`）—— 收成一副骨架

把四个方向的经验合成一个能装下**全部 13 个页面**的壳，并且导航由**插件清单**渲染：

```
插件清单 ──┬─ 梭上的位置（导航）
          ├─ 页面注册（路由）
          ├─ 命令（面板里带 owner 前缀）
          └─ 开关（关掉即不可达，可声明依赖）
```

- 关掉笔记 → 梭上少一枚 → 直接开 `#notes` 说「笔记 · 已关闭」→ 再打开就回来
- 关掉课程表 → 教务导入标成**阻塞**，导入页给出「它依赖课程表」
- **挂起**（群消息）：界面在，开关禁用
- **未实装**（记账）：位置在，功能没有，如实标注
- 四种材质（纸 / 水 / 图 / 场）随换随生效，骨架不动

### 工作台（`../design-demo/index.html`）—— 七种布局，同一份插件表

文字侧栏、图标栏、顶栏、悬浮栏、底部 Dock、顶部悬浮岛、专注菜单；八套配色可自由组合。12 个插件、15 个页面、六组导航同样从插件表读：

- 工作台也补齐了织机的三种生命周期：群消息**挂起**（页面可进、开关禁用、导航标「挂起」）、教务导入**依赖阻塞**（关掉课程表后入口一起收起）、记账**未实装**（只在插件页留一行状态）。
- 助手插件贡献「助手」页和工具栏命令，关掉后两处一起消失；导入页写明手动登录、抓完即关，CSV 导入不受开关影响。
- 插件页里可逐个开关；关掉日历，「此刻」少一项、计数从 4 变 3。
- 「装一批试试」最多注册 8 个合成插件、11 个页面，全部落进「新装」，总数从 15 到 26；可逐页打开，也可「恢复目录」回到 15 项。
- 横向布局的分组沿水平方向排开并自己滚动，两端渐隐；窄到 900px 时当前项仍保持在可视区。
- 所有资料只在内存中，不读写工作区。
