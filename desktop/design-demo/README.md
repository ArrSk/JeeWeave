# 几微电脑端设计实验室

## 当前版本 · 2026-11-08 · 插件状态与 15 页大纲

导航仍由 `catalog.js` 生成：12 个插件、15 个页面、六个分组（总览 / 此刻 / 记录 / 助手 / 系统 / 新装）与八支线色。`demo.js` 的 `renderNav()` 每次从目录重建组名、数量、线色与按钮；页面按需创建。工作区仍是示例资料，不读写真实存储。

插件除开关外，现在区分三种生命周期：

- **挂起**（群消息）：页面保留，可进入看说明；导航标「挂起」，插件页开关禁用。
- **依赖阻塞**（教务导入依赖课程表）：依赖关掉后，导入页、命令与导航位置一起收起；插件卡标「依赖阻塞」并写出原因，开关禁用。
- **未实装**（记账）：没有注册页面，只在插件页留一行「未实装」，不影响其他插件。

助手插件同时贡献「助手」页和右上工具栏命令，关掉后两处一起消失；助手页可预览一份示例草稿，输入内容只留在当前页面。导入页说明四步：准备入口、手动登录、读取课表、抓完即关；CSV 导入不受插件开关影响。群消息页写明适配器尚未接入。

- 插件页可开关插件；关掉日历会看到「此刻」少一项、数量从 4 变 3。
- 「装一批试试」最多注册 8 个合成插件、11 个页面，全部落进「新装」，总数从 15 到 26；可逐页打开，也可「恢复目录」回到 15 项。这是 demo 的压力演示，不是桌面端的新按钮。
- 横向布局（顶栏 / Dock / 悬浮岛）的分组沿水平方向排开，导航自己横滚，两端用渐隐提示；图标栏与悬浮栏隐藏组名，只留线色与图标；专注菜单展开后同样可滚动。
- 换页、装插件或改开关后，当前项会被滚回可视区，不会被长列表甩在窗外。

**边界**：后装插件是合成数据，插件名统一「后装插件」，页面名来自模板；没有拖拽排序、按插件二次分组或真实第三方插件。真正注册插件时若要让壳显示真名与真分组，需要给页面注册补元数据，本 demo 未改宿主契约。

## 两轴版本 · 2026-10-31

布局与配色完全独立，可在顶部选择器或预览按钮自由组合：**7 种布局 × 8 套配色，共 56 种组合**。选择配色不会切换布局、当前页面、示例事项状态或悬浮栏位置。

- 布局：文字侧栏、图标侧栏、横向顶栏、左侧悬浮栏、底部 Dock、顶部悬浮岛、专注菜单。
- 配色：澄白、墨蓝、雾青、暖砂、浅紫、石墨、玫灰、深海。
- 左侧悬浮栏 / Dock / 悬浮岛可通过把手在 demo 窗口内拖动；把手获焦后方向键微调、Home 复位。切换布局恢复默认位置。
- 专注菜单通过左上菜单按钮展开，也可用 Esc 收起；常规页面切换继续使用已有柔和过渡。

悬浮只发生在浏览器里的 demo 画布内；并非操作系统级悬浮窗口。演示不读取、写入真实工作区或正式外观设置。布局 CSS 与配色令牌分离，无新增依赖。

## Direction contract

THESIS：以对象和事情连接背景、时间与行动，减少常驻操作，常用动作靠近内容。此次是供用户选择的三份独立候选，不定义正式应用的新视觉规范。

OWN-WORLD：A 使用白与冷蓝、稳定侧栏；B 使用墨蓝分层、淡蓝强调和图标窄栏；C 使用雾青、深绿文字和横向导航。统一细线 SVG、系统阅读字体和 12px 内容圆角。

STORY：从今天看到约束，从事情理解目的，从原来源继续编辑；独立记录也有入口。避免把课程表当作整个产品的唯一结构。

FIRST VIEWPORT：稳定导航、轻工具栏、今日安排与当前事情上下文；新建、查找与助手各保留一个全局入口。详情在右侧出现，保留当前页面位置。

FORM：用户要求多套可体验候选，代码实现三种结构。Impeccable concept-seed 实际调用因缺少 PRODUCT.md 返回 NO_PRODUCT_MD，未完成随机方向分配；依据现有 README、HANDOVER 和对象设计直接实现候选，不将方案写成用户已确认的品牌方向。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 动效与验证

页面提前创建，以 CSS 过渡维持切换连续性；旧页面 inert，新页面立即可操作。导航指示器持续移动，详情侧栏独立滑入。没有强制 offsetWidth 重排或逐次重启关键帧。粒子按距离发射、按时间衰减，限制数量和画布像素比，无粒子或页面隐藏时停止循环；系统减少动态效果时隐藏粒子、缩短过渡。
