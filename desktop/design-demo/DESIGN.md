# 桌面独立候选的视觉记录

本文件仅约束 design-demo，不替换正式桌面端设计。候选均待用户体验与选择。

2026-10-31：当前拆为独立的 data-layout / data-palette 两轴。配色只声明颜色与 color-scheme，布局只声明结构与排布。原 A/B/C 解开绑定为文字侧栏、图标侧栏、横向顶栏；增加左侧悬浮栏、底部 Dock、顶部悬浮岛、专注菜单。颜色扩为八套，所有布局均可混搭。

悬浮栏统一使用实体背景、细 SVG、带偏移的柔软投影，留出默认内容安全区域；用户主动移动后可以覆盖内容，Home 可复位。专注菜单按需展开，按 Esc 或选择目标收起。布局选项用小结构示意、颜色选项用色点与名称，两个维度各自明确选中状态。布局结构切换不补间旧布局的 transform，保留常规页面与菜单过渡。

以下为初版的视觉参数与配色描述，现已独立使用，不再捆绑。

主内容使用 14px 系统字体，页面标题 29px，内容行 13–15px，元信息 11–12px；页面内边距 25–48px，相关内容紧邻、章节留白 28–35px。全局新建、查找、助手位于右上；危险或低频操作不占据主要阅读面。

A：白色工作面、浅灰侧栏、冷蓝强调，206px 文字侧栏。日程为主、关联背景为辅。

B：墨蓝工作面、深蓝侧栏、浅蓝强调，78px 图标侧栏。事情背景在左，时间安排在右；对象空间采用索引与详情双栏。

C：浅雾青工作面、绿色强调，72px 横向导航。内容采用更宽的左右留白，减少纵向侧栏占用。

动效只使用页面轻微位移与交叠、导航指示器滑动、详情侧栏进出和用户要求的低密度粒子。常规过渡 280–350ms，缓动 cubic-bezier(.2,.7,.2,1)，减少动态效果为 90ms 非空间反馈。方案比较切换会改变结构，不对整个布局执行补间。
