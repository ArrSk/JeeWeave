## 四、为什么"看起来和原来骨架区别不大"

一句话：**纸没有换。**

工作台的底色是冷蓝灰 `#f5f7fb`（`workbench.css:17`），经纬的底色是暖纸 `#f2efe7`。前者偏蓝、后者偏黄，**色相差了近 60 度**。人的眼睛对这个差异极其敏感——冷灰是"软件"，暖白是"纸"。

现在生产端把经纬装在冷灰上，**所有其他努力都会被这个底色吃掉**：线再准、纸条再薄，看上去还是"一个列表页加了一条竖线"。

第二个原因是**没有先兆句**。demo 里那句话是整页的"眼睛"：

```
现在 14:20 · 给导师回信 还有 6 分钟
```

它做了三件事：告诉你现在几点、告诉你下一件事是什么、告诉你还剩多久。**一秒钟之内给出"我现在该干什么"**。少了这句，页头就退化成"今天 · 11月2日 周一"，和原来一模一样。

第三个原因是**纸条是"啪"地出现的**。demo 里纸条错峰落下（每张差 45ms），经线从顶画到底。这两件事让页面在**进入的 0.9 秒里**表达出"时间在流动"。现在没有，所以进去就是一张静态图。

## 四之二、"还是块状"的第二个来源：容器框与其余 11 页

这一条比缺材质更根本，也是"看着像老设计"的真正原因。

### 一张纸与一个卡片的区别不在形状，在**位置是谁决定的**

| | 块的位置由谁决定 | 结果 |
| --- | --- | --- |
| 卡片阵列（老设计） | **排版**：12–16px 均匀间距，一块接一块 | 像表格，读起来是"列表" |
| 经纬 | **时间**：`top` 由分钟算出来，08:00 到 09:50 之间就该空 100 分钟 | 像日历，读起来是"一天" |

这就是为什么经纬里**空白是内容**，而卡片设计里空白只是"间隔"。

`loom-render.mjs` 确实按分钟算了 `top`，所以**今天页的这条是成立的**。问题出在别处。

### 问题一：其余 11 页仍是"框 + 老 panel"

`loom-shell.css:8`：

```css
.loom-content { border-left:1px solid var(--line-strong); padding-left:24px; }
```

`:53` 有一条例外：

```css
.loom-content:has(.loom-today) { border:0; padding-left:0; }
```

也就是说：**今天页没有框（对），但其他 11 页有一个 1px 的容器左边框，里面装的还是原来的 `class="panel"`**（`prototype-modules.js` 里有 **11 处** `panel`、10 处 `panel-head`）。

视觉结果是：进入经纬 → 看到时间轴 → 点"课程" → **立刻回到一个带边框的方框里装着卡片**。所以"块状感"不是没改掉，是**只改了一页**。

**修法**：把 `:has(.loom-today)` 的例外删掉，改成默认 `border:0`——框只该由经线承担，不该由容器承担。然后按 C 档逐页做经纬形态。

### 问题二：我自己的 demo 也有块，得说清楚

不是所有"块"都该消失。我的 demo 里明确保留了三种块，理由不同：

| 类 | 用在哪 | 为什么留着 |
| --- | --- | --- |
| `.plug`（`.plug-grid` 网格卡） | 插件页 12 项 | **它本来就是清单**：12 个开关必须并排扫视。硬做成时间轴反而更难用。**但它是唯一一处我认输的地方** |
| `.card` | 助手/群消息/导入的引用块 | 单条引文，不是阵列；一页最多 1 张 |
| `.skin-card` | 设置页材质 | 预览图必须并排比较 |

**判断标准**：一页里**成阵列的块（≥3 张同样大小、同样边框）就是"块状设计"回潮**；单张、有明确语义的块（引文、开关行、预览图）不算。

按这个标准自查：我的 demo 里 `loom.html` 的插件页有 12 张 `.plug` —— **这一页确实还是块状**。生产端如果要更彻底，插件页应该改成"一行一个插件、无边框、靠缩进和一条竖线分组"的清单，而不是 300px 网格。

### 问题三：`.loom-paper` 本身也可能变回卡片

现在它是 `background:transparent` + 底部发丝线（对）。但只要有人加一条 `border:1px solid var(--line)` 或 `border-radius:8px`，它立刻变回卡片——**它的"不像卡片"完全依赖那两行 transparent 和 `border-color:transparent`**。

建议在测试里加一条**结构断言**：

```js
// 任何 .loom-paper 的计算样式都不许出现四边边框或 >3px 圆角
getComputedStyle(el).borderLeftWidth === '0px'
getComputedStyle(el).borderRadius === '2px'
```

这样"块状回潮"会被测出来，而不是靠人眼看。

## 五、五条设计判断（这些比补特效更重要）

### J1 · 已经对的部分，别在后续改动里弄丢

连接短横线（`::before` 26px）、透明 rest 态、hover 才浮起、线上的结、呼吸环——**这五件是经纬的辨识度，它们已经在正确的位置上了**。

后面谁要是觉得"纸条太素了，加个卡片底吧"，经纬就没了。**纸条的素，是设计，不是缺失。**

### J2 · 经纬不是"时间轴 + 卡片"，是"经线与纬线的交点"

现在纸条**落在时间点上**（`top` 由分钟算），这是对的。但要注意：**纸条的垂直位置必须严格等于时间**，不能被避让算法推得太远。

现有 `floor` 避让是 11px 最小间距（`loom-render.mjs`）。三件事同刻时，第三张会被推到 22px 之下——**这时它已经不指向自己的时间了**。

demo 的解法：避让超过 40px 就**把时间标注改到批注栏**（右侧第三行），让纸条本体不再假装指向精确时刻。**这是"诚实"，也是"克制"。**

### J3 · 纸条正文要分三层，但不要塞成信息墙

你的数据比 demo 丰富得多，这是好事，但**不能全塞进纸条**：

```
标题            ← 14px，ink-1
为什么         ← goal，13px，ink-2      ← demo 没有，你的数据有，该显示
怎样算好       ← criteria，12.5px，ink-3  ← 同上
备注           ← note，11px，ink-3，最多两行
```

**批注栏**（右侧 108px）放事实：时间 / 地点 / 对象 / 阶段（有则显示）/ 执行段数（有则显示）。

**超过四行的内容不显示，点开才看。** 克制本身就是设计。

### J4 · 时间轴要分"过去 / 现在 / 将来"

demo 里：已过去 → `opacity:.7`；此刻 → 一条 accent 横线 + 呼吸点；将来 → 正常。

现在 `loom-render.mjs` 没有这个分层。**这是"读一眼就知道现在到哪"的关键**，比任何动画都重要。

### J5 · 页头不要统计数字

「N 次课 · N 项安排」是**给管理者看的**，不是给使用者看的。

页头只放一句先兆句。统计数字下移到页脚细行（demo 的 `.head-count`，11px ink-3）。

**A1 · 暖纸底**

```js
head.innerHTML = next
```

**A4 · 日尾**

```js
// 结构：.loom-tail > .loom-tail-line + .loom-tail-knot + .loom-tail-say
```

**A5 · 纸条落下 + 经线画下**

```css
[data-workspace-skeleton="loom"] .loom-paper{
  animation:loom-land .62s var(--ease-io) backwards;
  animation-delay:calc(var(--i) * 45ms + 220ms);
}
@keyframes loom-land{ from{opacity:0;transform:translateY(-9px)} to{opacity:1;transform:none} }

[data-workspace-skeleton="loom"] .loom-warp::before{
  transform-origin:top; animation:loom-draw .9s var(--ease-io) both;
}
@keyframes loom-draw{ from{transform:scaleY(0)} to{transform:scaleY(1)} }
```

> `backwards` 必须有——否则第一帧之前是会闪出来的。
> `:hover` 的 `translateX(3px)` 会盖掉 `land` 的 `transform`，所以 `land` 用 `animation` 且 `fill-mode:backwards`，结束后交还 `transform`。


## 九、我对这一版的判断

**方向对了，骨架对了，材料没上。**

Codex 这一版做对了一件关键的事：**它没有再"搬节点"，而是真的渲染了经纬的 DOM**（`.loom-paper`、`.loom-tick`、`.loom-warp` 都是新生成的，不是原列表项改的）。这是质的进步，说明渲染层方案（`loom-render.mjs` 87 行）走通了。

它漏掉的是**材料层**——暖纸、纸纹、衬线、先兆句、日尾、入场动画。这 6 件加起来不到 60 行代码，但它们承担了 demo 里 80% 的"高级感"。

**所以不是"做得不好"，是"只做了前一半"。** 前一半（结构）已经验收合格，后一半（材质）是纯 CSS。
