## 2. 根因（先说清楚再改）

**R1 · 只换了容器，没换内容。**
`loom-shell.css` 的第一条把整个 `section` 原地搬进 `.loom-surface`：

```css
[data-workspace-skeleton="loom"] .main>section { display:none!important; }
```

搬的是**原封不动的一坨**。生产端「今天」页的真实结构是 `.intro + .desktop-list + .panel`，而 demo 的经纬是「经线 + 刻度 + 纸条（三列批注）+ 此刻点」。**demo 有 `.slip` 的 DOM，生产端没有**，所以 Codex 只能把 `.desktop-list-item` 塞进新容器——格式当然不变。

**R2 · 旧样式被 `!important` 钉死。**
`design-pages.css` 有 7 处 `!important` 钉在页面内部元素上（`:28` 的 `.intro h1`、`:55` 的 `[data-page=today]>.intro h1`、`:38` 的 `.desktop-timetable-course` 的 border/background/color 等）。新骨架不动 DOM 就盖不住。

**R3 · 规格文档只写了「参考 jingwei.css」，没给令牌与 DOM 结构。**
Codex 手上没有 `--warp-x:120px`、`--hour:88px`、`.slip` 的三列栅格、`.tick` 的半小时节奏，只能做结构对齐。**这是文档的锅，不是 Codex 的锅**——修复单 §3 把这些给全。

**R4 · 三个小错是同一个原因：把「布局意图」实现成了「搬节点」。**
`skeleton-ui.mjs:9` 想实现「选经纬时布局区在下面」，于是 `append` 进别的 section；`focusPage()` 想实现「切页后焦点落到标题」，于是 `focus()` 没管 outline。

## 3. 必须补齐的经纬视觉规格（**逐项照抄，不要自由发挥**）

### 3.1 令牌（写进 `loom-shell.css` 的 `[data-loom-layout=jingwei]` 作用域）

```css
[data-loom-layout="jingwei"]{
  --warp-x:120px;      /* 经线距左边界 */
  --hour:88px;         /* 每小时像素，决定时间密度 */
  --gap:26px;          /* 纸条与经线的横向间隔 */
  --slip-margin-w:108px;
}
```

窄窗（≤900px）覆盖：

```css
@media (max-width:900px){
  [data-loom-layout="jingwei"]{ --warp-x:56px; --gap:18px; --hour:80px; }
}
```

时间窗口：`06:00` 起，18 小时（到 `24:00`）；若真实时刻 ≤ `05:00` 则从 `00:00` 起。

```js
// 换算（与 demo 完全一致）
const pxPerMin = () => (parseFloat(getCSS('--hour')) || 88) / 60;
const winStart = nowMin => (nowMin > 5 * 60 ? 6 * 60 : 0);
const yOf = (min, nowMin) => (min - winStart(nowMin)) * pxPerMin();
```

### 3.2 经线与刻度（DOM 结构，逐字照抄）

```html
<div class="loom-warp" style="height:{18*60*pxPerMin + 48}px">
  <div class="loom-warp-ticks">          <!-- 半小时一道，整点加长 -->
    <span class="loom-tick" style="top:{y}px"></span>
    <span class="loom-tick is-hour" style="top:{y}px"></span>
    <span class="loom-tick-label" data-min="{m}" style="top:{y}px"><b>08:00</b></span>
  </div>
  <div class="loom-now-mark" style="top:{yOf(now)}px">
    <span class="loom-now-dot"></span>
    <span class="loom-now-clock">14:20<i>此刻</i></span>
  </div>
  <ol class="loom-slips">…见 3.3…</ol>
</div>
```

刻度规则（**与 demo 一致**）：

```js
for (let m = start; m <= end; m += 30) {
  if (m % 60 === 0) {
    '<span class="loom-tick is-hour" …>'                 // 整点：11px 长
    if (m % 120 === 0 && m < end) '<span class="loom-tick-label" data-min="' + m + '"><b>' + hm(m) + '</b></span>'

```

**`is-muted` 规则**：距 `now` 26 分钟以内的 `.loom-tick-label` 加 `is-muted`（`opacity:0`），避免和此刻的钟点重叠。demo `jingwei.js:253` 就是这么做的。

## 4. 三个必须修的小错

### 4.1 `loomGroup` 搬错了容器

**位置**：`desktop/skeleton-ui.mjs:9`

```js
// 现状（错）
container.querySelector('[data-skeleton-section="workbench"]').append(loomGroup);
```

**后果**：实测 `[data-skeleton-section=loom]` 的父节点是「布局与动效」。用户选经纬后，四种布局出现在别人的标题底下。

**改法**：删掉这行。`loomGroup` 本来就住在骨架 section 里，**让它留在原地**；需要「骨架区在布局区之上」时，用 `skeleton-ui.mjs` 里 `container.prepend(section)` 的调用顺序解决（骨架 section 最后 prepend → 在最上）。

### 4.2 焦点框画在标题上

**位置**：`desktop/loom-nav.mjs:35` 的 `focusPage()`

**后果**：实测 `h1` 拿到 `outline: solid 2px rgb(47,89,238)`，截图上就是一个蓝框套住「今天」。

**改法**（两条都要）：

```css
/* loom-shell.css */
[data-workspace-skeleton="loom"] .loom-content [data-page] h1:focus,
[data-workspace-skeleton="loom"] .loom-content [data-page] h1:focus-visible{
  outline:none;
}
/* 保留键盘可见性：给可聚焦标题一个内敛的替代标记 */
[data-workspace-skeleton="loom"] .loom-content [data-page] h1:focus-visible{
  box-shadow:inset 2px 0 0 var(--accent);
}
```

```js
// loom-nav.mjs:35 保持 focus()，但改成只做「滚动到可见」，不抢视觉：
const focusPage = () => {
  const page = surface.querySelector('.loom-content > [data-page]:not([hidden])');
  const target = page?.querySelector('h1,h2') || page;
  if (!target) return;
  target.setAttribute('tabindex', '-1');
  target.focus({ preventScroll: true });
  target.scrollIntoView({ block: 'start', behavior: 'auto' });
};
```

> 理由：切页后焦点必须落到内容区（读屏与键盘需要），但**视觉上不该出现浏览器默认框**。

### 4.3 `Ctrl K` 冲突

**位置**：`desktop/loom-nav.mjs:53` 的 `keydown`

**后果**：实测 `Ctrl K` 打开「打开页面」面板，**原 `Ctrl K` 的全文查找被抢**。

**改法**：

```js
// 经纬的「打开页面」改为 Ctrl P
if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'p') { e.preventDefault(); e.stopImmediatePropagation(); openPalette(); }
// Ctrl K 不再拦截，交还给原 search-ui
```

并在 `loom-shell.css` 的按钮文案里把 `Ctrl K` 改成 `Ctrl P`：

```html
<!-- loom-nav.mjs 里那段 <button data-loom-command> -->
<button type="button" data-loom-command>页面 <kbd>Ctrl P</kbd></button>
```

**验收**：经纬模式下按 `Ctrl K` 必须打开原有「查找与整理」面板；按 `Ctrl P` 打开经纬的页面面板。

## 5. 页面内容的渲染方式（**这是"格式不变"的根治**）

### 5.1 为什么必须新增渲染层

现在 `loom-shell.css` 是「藏起原 section → 搬进 surface」。搬的是原 DOM，所以内部格式一个像素不变。
**必须改成「经纬模式下不显示原 section，改用新渲染」**：

```
workbench 模式  → 原 section 显示（现有逻辑，一个字不改）
loom 模式       → 原 section 全部隐藏；.loom-surface 里渲染经纬专用的 DOM
```

### 5.2 新增文件 `desktop/loom-render.mjs`

职责：**只读数据 + 生成 DOM**，不写库、不发命令、不碰插件开关。

```js
export function createLoomRenderer({ host, modules, bindings }) {
  // 统一的取数入口，全部走现有服务
  const api = {
    today:  () => host.client('today').query(today()),     // 返回 { scheduledItems, … }
    items:  () => host.client('items').list(),
    courses:() => host.client('courses').list(),
    objects:() => host.client('objects').list(),
    notes:  () => host.client('journal').list(),
    web:    () => host.client('web-captures').list(),
  };

  // 每个布局一组渲染函数，返回 HTML 字符串
  const jingwei = {
    today:  () => renderWarp(api.today()),      // §3.2 ~ §3.5
    courses:() => renderSevenThreads(api.courses()),
    objects:() => renderLongLines(api.objects()),
    other:  (id) => renderPlain(api[id]?.() ?? []),   // 其余页先保持现有版式
  };

  return { render(id, layout='jingwei') { … } };
}
```

### 5.3 落地顺序（**每步都能跑**）

1. **先只做 `today`**：经纬模式下今天页用 `renderWarp()`，其余页继续显示原 section。
2. 验收 §3.6 六条 → **这一步就能看到「和 demo 对得上」**。
3. 再做 `courses` 的七缕、`objects` 的长线。
4. 其余页（calendar/notes/web/…）本轮**保持原样**，只是放进 surface 里（样式后续再跟）。

> **不要一次性把 13 页都重渲染。** 每加一页就跑一遍 §6 的可达性表。

### 5.4 状态归属（重要）

`loom-render.mjs` 只负责**画**。以下仍归现有模块，不得复制：

| 状态 | 归属 |
| --- | --- |
| 完成 / 撤销完成 | `host.client('items').toggle()` |
| 新建/编辑 | `host.run('items.edit')` 等现有命令 |
| 数据变化后的重绘 | 订阅现有 `onChange` 链（`syncModules` / `refresh`） |
| 滚动位置 | `.loom-surface` 自己的 |
