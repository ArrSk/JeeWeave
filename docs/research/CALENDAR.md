# 桌面日历：参考与落地

2026-10-18。用户选择默认月视图，当前开发目标是 Desktop 的待办/计划日历。

参考 [Apple Calendar 视图说明](https://support.apple.com/guide/calendar/change-how-you-view-events-icl28064/mac)与[官方日历示例](https://support.apple.com/guide/calendar/welcome-icl8c17e7f55/mac)：保留月／周／日、今天与前后日期、全天区域、轻量网格和当天详情。参考 [Schedule-X](https://github.com/schedule-x/schedule-x) 的多视图日历结构；没有安装其组件或迁移桌面技术栈。[FullCalendar 的事件说明](https://fullcalendar.io/docs/event-parsing)区分全天和带时段事件，明确结束时间不包含在区间内；用于核对跨午夜的显示边界。

实际实现为原生 HTML/CSS/ES Modules。`calendar.mjs` 从现有 plans/tasks 派生展示条目，`calendar-ui.mjs` 负责视图与交互。已有完整业务记录仍是唯一数据源，编辑链接复用计划/待办表单，不另存一份日历事项。

- 全天日期区间包含结束日；具体时段结束时间不包含在区间内，00:00 结束不会再在下一天产生事件。时间统一按上海时区展示。
- 持续区间与截止是不同条目；截止只出现在准确日期，不把“已逾期”画成以后每天都有的安排。
- 每周重复按星期、开始日和可选结束日展开，完成记录只影响选中的那次。阶段有独立日期才绘制；无日期阶段保留在详情中。
- 月视图按周拆分跨日条目。拥挤时优先保留主色条与截止项，“另几项”打开当天完整清单。周/日区分全天和时段，全天区域可独立滚动；相交时段分列。短事件使用最小可点高度，界面明确提示以详情中的精确时间为准。
- 无日期事项单独显示；关闭某来源模块后不再显示它的数据。已完成内容默认收起，可勾选显示。
- 切页、日期、视图、筛选、详情、课表周次/设置页签与编辑面板复用可打断动画；系统减少动态效果时仅淡入。

验证使用隔离虚构资料，覆盖范围与证据见 [HANDOVER](../HANDOVER.md)。无拖拽改期、日历订阅、外部同步或通知能力；没有添加到产品能力表。
