## 对用户所说 dsh 的核对

已找到 DeepSeek AI 官方的 **DeepSeek Harness（dsh）**，不是根据简称猜测其他项目。其 README 明确以 Cordis 支撑“万物皆插件”，并标注为快速迭代的开发者预览版。架构文档还将模型、工具、会话与执行循环都放入插件组合，服务边界区分定义、实现和消费者。以上依据是官方当前资料，不是本地试运行结论。

几微借鉴的是可替换服务、显式依赖、可撤销注册这些机制。它是个人工作台，数据恢复、窗口、安全桥接和界面交互有自己的约束；不能由“理念相同”直接推出“应当安装整套 Harness”，也不能直接把其代理循环当成几微的数据流程。

## 本项目的结论与待核实项

- 随记与事项独立：记录可以长期没有截止、没有归属，也不需要变成待办。
- 业务能力逐步成为内置插件，底座只统一运行、接口、持久化机制与平台边界。对象聚合通过提供者读取原记录，不抄一份正文。
- 框架选型尚未决定。后续用小范围实验比较轻量宿主与 Cordis：离线启动、体积、资源释放、依赖缺失、存储事务、受限 IPC、许可证及维护成本。当前不承诺热更新或第三方市场。
- 本次工具清单无可调用的 Context7 resolve/query 工具，**未完成 Context7 查询**。使用上述官方资料核实设计来源，没有验证第三方 API 用法或安装配置；进入具体框架实现时需重新查询对应版本文档。
