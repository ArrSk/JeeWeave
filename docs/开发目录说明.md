## 常用入口

- 日常使用：`desktop/release/几微-0.2.1-Windows-20261020-050440/几微.exe`。保持整个文件夹完整，ZIP 和校验文件位于同级。
- 0.2.1 增加统一事项、对象 Beta、课程文件与单次调整移植、品牌界面及开发者清空；旧成品和其中 data 保留作回退及历史恢复。
- 桌面启动：`desktop/debug.cmd` 或 `pnpm desktop:run`；原文与示例在“设置 → 开发者模式”开启。
- 桌面封装：`desktop/package.cmd`，通过成品原目录普通启动检查才报告成功。
- 网页开发：`web/启动开发服务器.cmd`；网页成品：`web/预览成品.cmd`。
- 基础检查：`pwsh -NoProfile -File scripts/verify.ps1`；桌面单测：`pnpm desktop:test`；网页交互：先构建再 `pnpm web:test:ui`。

`prototype.html`、`prototype-modules.js` 虽然带历史名称，仍是桌面主界面，不能当废弃原型删除。网页端使用独立 React 客户端，不读取桌面课表。
