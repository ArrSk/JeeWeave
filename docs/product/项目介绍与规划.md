# 几微 · JeeWeave 项目介绍

更新：2026-10-21。当前可用能力与目标设计分开说明；平台对照见[项目 README](../../README.md)。

## 它要帮助用户做什么

几微希望帮助用户把一件事办成：知道它属于哪门课或哪个项目、为什么做、要交付什么，以及今天怎样推进。名字里的“几微”强调细小但重要的日常，“Weave”表示把零散的信息和行动织回同一件事。

用户可以从课程表、事项和日历进入，每个入口都应保留来由和目标。Desktop 对象视图 Beta 已能以课程/项目/主题组织上课安排、事项和网页资料，手动建立主归属并双向跳转；多段独立投入和今天按事情组织仍在后续范围。详见[对象与事情设计](对象与事情设计.md)。

## 目前实际可用

Desktop 是当前开发主线，已有多课表、课程增删改、单双周/连堂、教学周与逐表作息、南邮 WebVPN 手动登录后实时导入、未排课记录、计划/待办及阶段/重复、月周日日历、公开静态网页整理、主题、内置开关和统一本地备份。示例入口在开发者模式中显示。

Web/PWA 是独立客户端，有自己的界面、数据服务与备份；两端数据不能直接互相恢复。Desktop 本地源码已补齐单次调课/停课与恢复、CSV/ICS 预览、今天状态与阅读设置，不能据此宣称旧 Release 已更新。桌面业务保存到 data/workspace.json，Web 保存到浏览器数据库。

本地开发版新增随记：直接键入每日感悟、感受、想法与经验，草稿即时保留，按日回看、搜索、归档或导出 Markdown。无需先填写标题、建目录或变成任务；数据同工作区备份迁移。

群消息开发暂停，界面和接收停用，代码及历史资料保留。记账、完整知识库、同步、原生闹钟、第三方插件安装和 APK 都不是当前成品；对象关联仅包含 Beta 说明中的主归属功能。公开 Windows 0.2.1 不含此次随记与宿主首片，见[交接说明](../HANDOVER.md)。

## 接下来的设计

先体验独立随记，再开发关联课程/项目、确认提炼行动。底层首片已提供服务、命令、导航和资源清理，接入随记与对象/事项只读桥接；完整引用和跨提供者写入尚待后续。之后继续多段投入、工作台按事情归组与逐模块迁移，记账仍单独安排。

范围和流程分别见[随记](随记功能与开发流程.md)与[插件化底座](../design/插件化底座与迁移流程.md)，官方参考包含 Memos、Logseq 和 DeepSeek Harness，见[调研](../research/随记与插件架构案例.md)。N1 仍为本地开发能力，尚未新增发行包、第三方插件安装或真实数据迁移。

无需先填写复杂分类：独立待办、无日期内容和待归类资料继续存在。用户可以直接完成简单事情；是否拆步骤、关联某节课、填写目的由需要决定。

本地优先、旧资料兼容和失败不覆盖继续作为约束。近期切片见[路线图](../ROADMAP.md)，技术边界见[架构说明](../ARCHITECTURE.md)。
