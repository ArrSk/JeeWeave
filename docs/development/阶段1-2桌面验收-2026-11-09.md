# 阶段①②桌面开发与集中验收

日期：2026-11-09。基线：`pc / d6bc436` 加会话开始时已有本地改动和本轮新增改动。范围由用户明确为①记录、找回和改正，②对象与多视图；AI 自然输入与合理性分析留到下一轮。这里记录本地源码与工程验证，不替代用户对设计的认可。

## 最终行为

| 场景 | 结果 |
| --- | --- |
| 先记后理 | 正文即可记录，不用起标题、选择用途或关联对象；记录日期默认填写。草稿切页与重开可继续，Ctrl+K 找回原文，编辑保持 ID。 |
| 改错与恢复 | 误改笔记草稿可取消放弃或确认放弃；确认后原已发表笔记不变。事项完成与撤销复用既有机制；本轮没有新增已保存正文的版本历史。 |
| 时间分别处理 | 执行时段、截止和独立提醒分别编辑；改时段不改截止，改截止不重排时段，提醒改期不改写事项。 |
| 从对象看时间 | 对象全貌提供按日、周、月看，只读取该对象原记录与关联课次；无日期事项留在未定日期区域。可随时返回全部日历。 |
| 原记录和来源 | 事项、时段、对象关联以及课程 tableId/courseId 保持身份；对象和事项双向打开。课程记录可查看所在课表，课次投影沿用调出/停课/调入语义。 |
| 改期后返回 | 日历中编辑已有事项在原页打开弹层，保存或取消后保持原周；保存反馈不推动原浏览位置。 |
| 关闭和故障 | 对象关闭时范围查询明确提示，可返回全部日历；不悄悄取消筛选。提醒注册失败恢复原资料并尝试恢复旧系统任务，冲突拒绝覆盖，表单失败保留输入。 |

对象筛选只存在于呈现层内存，切日/周/月和编辑后保留；跨骨架不传递临时筛选，不新增业务副本。课程按钮打开该课程所在整张课表，并非只显示一门课的全新课表。原工作台和经纬保持独立。

## 实现与契约

- `calendar-service.mjs` 查询增加可选对象范围，通过 objects / items / courses 公共服务读取；按集合及表 ID 匹配，避免同名或同编号跨集合串改。相关提供者关闭或失效时保留原关联并报告边界。
- `object-view-ui.mjs`、两套日历呈现和公共命令接入同一查询；现有对象、来源、取消和生命周期继续复用。
- `reminder-platform.cjs` 增加保留 ID 的 update；编辑签名排除异步投递回执，写入串行并验证旧快照。提醒类型保持原值，每日投递历史保留。系统恢复失败会明确要求重新注册，不伪装恢复成功。
- 提醒编辑提交禁重、错误保留、关闭/重开代际守卫；旧请求结果不关闭新编辑器；已用人为延迟的隔离桥验证重新打开后输入不被覆盖。没有新增常驻任务、账号、模型调用或后台收集。

完整参数、同步/异步、提交点和失败语义见[内置插件接口](内置插件接口.md)末尾。工作区和备份 schema 未改。

## 本地体验与边界

运行 [desktop/debug.cmd](../../desktop/debug.cmd)，在设置选择经纬：

1. 笔记 → 记一笔 → 只填正文 → 收起 → 切页 → 继续写；保存后 Ctrl+K 找回，再试放弃编辑草稿。
2. 对象视图 → 打开对象 → 添加或关联作业、笔记和课程；按日/周/月查看，核对范围提示及原记录。
3. 周视图打开作业，分别修改截止与执行时段，保存后核对周、位置和对象；关联课程可跳到所在课表。
4. 提醒 → 新增或编辑/改期 → 单独保存，核对事项截止与执行时段保持不变。
5. 设置返回工作台，重复关联和编辑入口，确认旧版仍可用。

仍需用户体验确认：首次独立操作耗时、求助位置、真实中文输入法、读屏、深色逐屏目测、真实旧资料及一周使用中的打扰。Windows 关机/休眠/系统策略下的真实定时投递没有在本轮设备实测，不能据替身测试承诺必达。当前没有新的性能基准或一周使用数据。

本轮不扩展 AI 两阶段、不移植手机、不打包、不提交、不推送；想法库中的未排期和暂停项保持原状态。
