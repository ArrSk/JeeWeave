# 桌面端与网页版功能对照

检查日期：2026-10-20；2026-10-21 补随记与内置开关差异。对照本地 Desktop / Web 实际代码；未把已部署网站、历史说明或模型中的预留字段当作已验收功能。此表是当前差异清单，不表示本轮已将所有差异移植。

## 主要结论

桌面目前在统一事项、阶段任务、日历、南邮教务抓取、公开网页整理和主题配色方面更完整。本轮已按用户授权移植单次调停课、ICS、课程批量字段、今天课程状态和阅读显示设置。两端分别保存数据，备份不能直接互相恢复。

对照后的推荐移植已完成（本地开发源码）：课次调整、文件预览、ICS、批量字段、今天状态、阅读设置；Web 仍独立维护。

## 课程与今天

| 功能 | Web 当前实现 | Desktop 当前实现 | 差异与影响 |
| --- | --- | --- | --- |
| 多课表管理 | 新建、切换、删除学期/课表 | 新建、切换、删除，独立作息 | 两端都有，数据和实现不同 |
| 周/日与周次 | 教学周、前后周、本周、单日 | 教学周、前后周、本周、单日 | 两端都有；桌面设置在局部覆盖面板 |
| 课程增删改 | 名称、教师、地点、星期/节次、周次、颜色 | 对应字段及逐周选择、单双周、连堂 | 核心能力都有，不能仅按表单外观判断完整移植 |
| 卡片配色与正文 | 按名称派色或选七色，课名换行 | 同组七色并适配桌面主题，教师/教室/周次/节次分行 | 桌面强调完整文字及重叠课程分列 |
| 批量课程编辑 | 名称、星期、起止节次、周次 | 名称、星期、起止节次、教师、地点、周次 | 本轮补齐，整批校验保存并保留身份 |
| 单次调课/停课/恢复 | 基于课次处理调入/调出、停课及恢复 | 已移植，课表/今天/日历均可进入 | 桌面以课程 ID + 原日期识别，不改整学期模板 |
| 作息编辑 | 逐节编辑、分时段安排、增删节次、恢复预设 | 逐节与上午/午后/晚间批量，课长/间隔/大课间生成预览 | 两端都有，批量参数和布局不完全相同 |
| CSV 导入/导出 | 可编辑预览、格式校验、重复跳过/冲突提醒 | 已移植，可逐行修正或明确跳过，确认前不写入 | 桌面补充旧预览覆盖保护，CSV 仍为模板 |
| ICS 文件 | 课程 ICS 导入，按课次导出 | 已实现，按有效课次导出；支持具体课次及有限每周规则 | 桌面复杂覆盖/未知时区显式报错，非通用任意 ICS 导入 |
| 南邮 WebVPN | 未接入登录会话与实时抓取 | 手动登录、实时帧树抓取/解析、单双周、教师地点、完整性校验 | 桌面独有；校网环境及学校页面仍影响使用 |
| 教务未排课项 | 没有同类教务导入清单 | 其它课程保留原文与周次，列为待安排，不编造星期/节次 | 桌面独有 |
| 今天的课程 | 具体课次、上课中/下一节、调停课结果 | 已补齐状态卡和调整结果，显示期间定时更新 | 未设开学日不伪造具体课次 |
| 今天的事项 | 从 Block 规则派生今日内容，计划/待办可分别关闭 | 从原两集合派生，统一“查看事项”，包含无期限待处理内容 | 分类、逾期和无期限展示策略不同 |

## 事项与日历

| 功能 | Web 当前实现 | Desktop 当前实现 | 差异与影响 |
| --- | --- | --- | --- |
| 计划/待办入口 | 计划和待办独立页面；部分 task 也能在计划中出现 | 合并“事项”列表/编辑器，按时间语义分类 | 桌面已减少重复入口，保留旧两集合身份 |
| 截止/无期限 | 两者都有；计划页可设截止时刻，待办表单只设日期 | 同一编辑器可设日期/具体截止时刻或无期限 | 桌面旧待办原地改时间语义，不复制记录 |
| 事件/考试 | 一个“事件 / 考试”选项，填写当天起止 | 本轮改为一个“事件 / 考试 · 当天时段”选项 | 用户选项统一；桌面历史 exam 标记兼容保留 |
| 全天 | 旧 allDay 可显示；计划表单没有单独全天选项 | 单独“全天事项”选项 | 不把全天强塞进具体时段 |
| 跨日区间 | 起止日期 | 起止日期及可选时刻 | 桌面支持带具体起止时刻的区间 |
| 阶段任务 | 当前界面未提供阶段编辑器 | 区间内一级阶段、可选日期、独立完成状态 | 桌面已有，不能误认为已移植回 Web |
| 执行区间与硬期限 | 计划表单主要选择一种时间类型 | 区间/事件/重复安排另有可选独立截止 | 桌面将“何时做”和“最晚何时完成”分开 |
| 每周重复 | 星期、开始/结束日、时段、单次完成 | 同类能力，并可不设具体时段 | 两端都有，桌面可选全天式重复 |
| 列表范围 | 计划页仅显示与今天起 45 日窗口相交的内容；待办列表另行读取 | 事项列表保留全部日期，可按类型/完成筛选 | 旧事项看不见时需检查窗口与入口，不宜直接判为丢失 |
| 独立事项日历 | 没有月/周/日事项日历 | 月/周/日、日期跳转、区间/阶段/截止、无日期清单 | 桌面独有；内容为投影，不另存完成状态 |
| 小时与截止点 | 主要在列表描述时刻 | 月视图显示时刻，周/日将时段定位，具体截止是时间点 | 带时间的截止不再冒充全天 |
| 冲突与编辑联动 | 列表编辑 | 日历相交时段分列、详情、原记录编辑和单次完成 | 桌面日历不是第三份业务数据 |
| 课程在日历显示 | 可导出课程 ICS，没有同一事项日历界面 | 课程课次已与事项同历显示，含调停课标记和详情跳转 | 桌面新增课程筛选，不另存第二套课次 |
| 对象与课程/事项关联 | 未实现课程/作业对象闭环 | 对象视图 Beta：课程/项目/主题、主归属、聚合详情、原记录编辑和返回 | 手动确认归属；多相关对象/单次课来源/多执行安排仍未实现 |

## 本轮推荐移植的落地范围

1. 单次调停课及恢复：先明确逻辑课次身份、备份和今天/日历的一致性，不能仅新增按钮。
2. 批量课程字段补齐、CSV 可编辑确认预览和 ICS：保护已有课表，先预览再保存，保持失败回滚。
3. 今天的上课中/下一节、阅读字号与密度：复用桌面主题/设置，按现有窗口尺寸验证。

以上三组已按用户“进行你推荐的移植”授权完成并验证；后续课程/事情关联、订阅、同步与打包不包含在本轮。具体 ICS 限制见 [Desktop README](../../desktop/README.md)。
