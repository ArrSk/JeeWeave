## 当前实现与边界

- 主线为 Desktop：Electron 44.7.0 + HTML/CSS/ES Modules；Web 为独立 React/PWA，公共层主要服务 Web。两端数据不自动互通，不能直接互相恢复备份。
- 桌面包含多课表、单双周/连堂与未排课记录、逐表作息、单次调停课/恢复、南邮 WebVPN 手动登录后实时导入、CSV/ICS 预览与导出。课程表、今天状态与日历共用有效课次投影。
- 计划/待办统一为事项入口，事件/考试共用选项，保留截止、时段、全天、阶段和重复。旧 tasks/plans 集合与 ID 保留，不按标题合并；日历按真实时刻和期限投影。
- 对象视图 Beta 可手动关联课程排课、事项、笔记和网页原文，双向返回原编辑器；一来源一主归属。普通非重复事项可保存多段执行安排，今天按原事项汇集，日历显示执行时段与独立截止。复杂重复/阶段组合、单次课堂布置来源仍待开发。
- 本地笔记 N1/N2（原随记）：「记一笔」直接输入，用途可选见闻/感受/想法/摘录/复盘，默认未分类；可选标题/标签、补记日期、即时草稿、时间轴/筛选、归档/回收站及 Markdown 导出。可关联对象并从选文确认创建事项，保留原文与双向来源；提炼草稿、引用和时段与 JSON/data 同迁移。
- 侧栏显示 JeeWeave · 几微，无原生左上菜单；统一弹层最大 820px，主题/字号/密度集中设置，切换为可打断的轻量淡入。8 项内置开关现已接入清单/依赖/版本、服务/命令/引用路由、命名空间与启停生命周期；仅运行可信内置代码，第三方安装/隔离未实现。
- 示例入口、读取和导入服务均受开发者模式控制。开发者可确认后清空：重启前停止写入，旧进程退出后完整归档到同一 data/backups，再初始化空白环境；失败回滚，不永久删原资料。
- QQ/微信群接收及入口暂停，代码与历史资料保留。记账、完整知识库、外部 AI、同步、原生闹钟、第三方插件安装与 APK 尚未完成。

数据权威为同一 data/workspace.json；会话、原文、导出和备份均位于 data。升级先退出应用、备份，再整体复制 data；来源和兼容约束见[数据格式](../../desktop/DATA_FORMAT.md)。各轮实际资料检查范围单独记录，发布包不应包含用户资料。
