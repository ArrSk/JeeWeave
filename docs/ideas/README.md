## 怎样收录和推进

- 不成熟的想法都先收下，不要求有完整方案、收益估算或验收标准。分类不确定先放[收件箱](收件箱/README.md)，只有一句原话也可以；不确定的信息写“待明确”。
- 记录原意与来源日期；把用户原话、文档整理和后续推测区分开。相近条目补充到原编号，不按相同名称自动合并。
- 文件夹可以重命名、移动或继续嵌套，编号不变；同步本索引和已有链接。当前目录为便于浏览的分类，不是固定的数据结构。
- 条目可标“待细化”“待验证”“暂停”“已转入路线图”或“暂不做”，状态独立于所在文件夹。暂停项保持暂停，收录不自动恢复开发。
- 用户决定推进时，补具体场景、范围与验收，链接到[路线图](../ROADMAP.md)，原条目保留来源和去向。应用功能继续遵循桌面体验、用户确认、再按授权移植或发布的顺序。
