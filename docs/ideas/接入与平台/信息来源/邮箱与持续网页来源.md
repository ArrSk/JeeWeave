# 邮箱接入与持续网页来源

编号：IDEA-011  
状态：待细化，未排期  
收录：2026-11-09

## 想法

用户选择邮件或网页来源，保留原文及更新证据，再确认整理结果。

## 尚未想清楚

读取范围；来源更新、去重、断开和凭证清理；是否需要持续抓取。

## 何时再讨论

先选一个来源和授权范围，重新核实接口并验证退出恢复。

## 当前边界与来源

现有手动网页采集不等于邮箱接入或持续订阅；旧接口研究不是当前验证。
