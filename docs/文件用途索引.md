## 桌面成品中的文件

这些文件位于 desktop/release/几微-0.1.0-Windows-20261017-035650/。运行资源应保持相互位置，日常只需双击几微.exe。

| 文件或目录 | 用途 |
| --- | --- |
| 几微.exe | 桌面应用入口，包含 Electron 的程序引擎 |
| 使用说明.txt | 本地启动、备份、升级及数据位置说明 |
| resources/app.asar | 封装后的桌面源码与公共日期函数，修改源码不会自动更新这里 |
| resources/default_app.asar | 本机 Electron 分发附带的默认启动资源，当前整包保留 |
| locales/*.pak | 浏览器内核的各语言资源 |
| chrome_100_percent.pak、chrome_200_percent.pak | 标准/高缩放屏幕的浏览器界面资源 |
| resources.pak | 内核通用资源 |
| icudtl.dat | 国际化、字符及区域数据 |
| snapshot_blob.bin、v8_context_snapshot.bin | JavaScript 引擎初始化快照 |
| ffmpeg.dll | 媒体解码运行库 |
| d3dcompiler_47.dll、dxcompiler.dll、dxil.dll | Windows 图形与着色器支持库 |
| vk_swiftshader.dll、vk_swiftshader_icd.json、vulkan-1.dll | 图形后端及软件绘制支持 |
| LICENSE.electron.txt、LICENSES.chromium.html | 随运行时分发的第三方许可证 |
| version | 当前 Electron 运行时的版本标记 |
| data/manifest.json | 版本化数据目录的相对路径与格式说明 |
| data/workspace.json、workspace.previous.json | 当前和上一次业务快照，含课表、计划、待办、网页记录和偏好 |
| data/profile/ | 登录会话和兼容缓存所在的持久 profile，不能当普通缓存删 |
| data/captures/ | 网页采集原文和元数据 |
| data/cache/ | 成品浏览器磁盘缓存，和 profile 分开 |
| data/logs/ | 错误日志及崩溃诊断 |
| data/exports/、data/backups/ | 业务导出/下载和确认恢复前的独立快照 |
